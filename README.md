# news-image-20261121

One image summing up the world's news of **Saturday 21 November 2026**:
Wall Street's worst week since April, the capture of cartel boss
"El Chapo Isidro" in Mexico, the double-tap strike on Kryvyi Rih,
COP31 stalling in Antalya, and a 6.7 earthquake in Peru.

`main.py` (Python 3, standard library only) copies the bundled
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`.

Entry for the make.fun competition `news-image-20261121`.
